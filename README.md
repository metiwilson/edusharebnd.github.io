# 📚 لینک درس‌ها — دانشگاه آزاد بندرعباس

مرجع جمع‌آوری لینک گروه‌ها و کانال‌های درسی دانشگاه آزاد بندرعباس در یک صفحه‌ی ساده و سریع.

🌐 **دموی آنلاین:** [edusharebnd.github.io](https://edusharebnd.github.io)

---

## درباره پروژه

این وب‌سایت به دانشجویان دانشگاه آزاد بندرعباس کمک می‌کند تا لینک گروه‌های درسی خود را سریع پیدا کنند و مستقیم وارد شوند. تمام لینک‌ها توسط خود دانشجویان جمع‌آوری و به‌روزرسانی می‌شوند.
